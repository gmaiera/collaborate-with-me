# Security Policy

## Public Repo Notice

This repository is public and may be served through GitHub Pages. Publish only content intended for public collaboration.

Do not publish live credentials, private strategy, customer data, `.env` values, tokens, internal IPs/ports, local runtime state, or internal-only operating notes.

## Reporting

Report sensitive-content or credential exposure privately. Do not include secret values in public issues, pull requests, comments, screenshots, or logs.
